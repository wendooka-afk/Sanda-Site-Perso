C'est quoi Claude Code (et pourquoi il fait le buzz)

Claude Code est l'outil de programmation en ligne de commande d'Anthropic. Il vit dans votre terminal, lit et modifie vos fichiers, lance des commandes et exécute des tâches de développement complètes - pas seulement répondre à des questions.

La différence avec un chatbot classique est nette. Vous ne copiez plus du code à la main. Vous dites « ajoute une page de contact à mon site », et Claude Code lit votre projet, écrit les fichiers, corrige les erreurs et teste le résultat. C'est un agent, pas un assistant.

C'est ce qui en fait l'un des outils les plus puissants du vibe coding : construire des logiciels en décrivant ce que vous voulez, en langage naturel. Le problème ? Cet outil n'est pas gratuit par défaut.

Ce que vous allez apprendre dans ce guide
Faire tourner Claude Code sur votre propre ordinateur, gratuitement, en le branchant sur des modèles d'IA open-source (Qwen, DeepSeek, Llama). Aucun abonnement, aucune clé API payante, aucune carte bancaire. La méthode est légale et fonctionne sur Windows, Mac et Linux.

Pourquoi Claude Code coûte normalement de l'argent

Claude Code est gratuit à télécharger, mais il a besoin d'un « cerveau » payant pour fonctionner : les modèles Claude d'Anthropic, facturés à l'usage. Il existe deux façons officielles de le payer.

Option 1 - Un abonnement Claude

Claude Code est inclus dans les abonnements Claude. Le plan Pro coûte 20 $/mois (~13 000 FCFA) avec des limites d'usage. Le plan Max démarre à 100 $/mois (~65 000 FCFA) pour un usage intensif.

Option 2 - Des crédits API (paiement à l'usage)

Vous pouvez aussi connecter Claude Code à une clé API Anthropic et payer chaque token consommé. Sur un vrai projet, la facture grimpe vite - quelques dollars par heure de travail intensif.

⚠️ Le vrai blocage pour beaucoup d'Africains
Au-delà du prix, ces deux options exigent une carte bancaire internationale (Visa/Mastercard) acceptée par Anthropic. Pour beaucoup d'entrepreneurs et d'étudiants en Afrique francophone, c'est le premier mur. La méthode de ce guide contourne ce mur entièrement - légalement.

L'idée centrale est simple. Claude Code n'est qu'une interface. On peut remplacer le « cerveau » payant (Claude) par un cerveau gratuit qui tourne sur votre propre machine.

L'astuce : faire tourner Claude Code sur des modèles open-source en local

La méthode gratuite consiste à brancher Claude Code sur un modèle d'IA open-source qui tourne sur votre ordinateur, via un logiciel appelé Ollama. Vous gardez l'interface de Claude Code, mais le calcul se fait chez vous, sans payer Anthropic.

Trois pièces composent le montage :

  • Claude Code - l'interface en ligne de commande (l'agent qui lit et écrit vos fichiers).
  • Ollama - le moteur gratuit qui fait tourner des modèles d'IA en local sur votre machine. Voir le site officiel ollama.com.
  • claude-code-router - un petit « traducteur » qui fait croire à Claude Code qu'il parle à Anthropic, alors qu'il parle à Ollama.

Pourquoi un traducteur ? Parce que Claude Code parle le langage de l'API Anthropic, et Ollama parle le langage de l'API OpenAI. Le routeur claude-code-router traduit entre les deux. C'est lui qui rend le branchement possible.

Pourquoi c'est 100 % légal
Claude Code prévoit officiellement une variable ANTHROPIC_BASE_URL pour pointer vers un autre serveur. Vous ne piratez rien : vous utilisez une fonctionnalité prévue, avec des modèles open-source sous licence ouverte. Vous n'utilisez jamais les modèles Claude sans payer - vous utilisez d'autres modèles, gratuits.

Ce qu'il vous faut avant de commencer

Avant le tutoriel, vérifiez que vous avez le minimum. Rien de tout cela n'est payant.

  • Node.js installé (version 18 ou plus). À télécharger sur nodejs.org. C'est nécessaire pour installer Claude Code et le routeur.
  • Un terminal - l'invite de commande Windows (PowerShell), le Terminal sur Mac, ou bash sur Linux.
  • De la RAM - minimum 8 Go pour un petit modèle, 16 Go recommandé pour de meilleurs résultats.
  • ~10 Go d'espace disque libre pour télécharger un modèle.
  • Une connexion internet - uniquement pour l'installation et le téléchargement du modèle. Ensuite, tout fonctionne hors ligne.
Bon à savoir sur le matériel
Pas besoin d'un ordinateur de gamer. Un PC ou Mac récent avec 8 à 16 Go de RAM suffit pour démarrer avec un modèle 7B. Plus votre machine est puissante (surtout avec une carte graphique), plus les réponses sont rapides et le modèle peut être gros.

Tutoriel : Claude Code gratuit avec Ollama en 6 étapes

Voici le processus complet, de zéro à un Claude Code fonctionnel et gratuit. Comptez 15 à 20 minutes, dont le temps de téléchargement du modèle.

1

Installer Claude Code

Ouvrez votre terminal et installez Claude Code via npm :

npm install -g @anthropic-ai/claude-code

Vérifiez l'installation avec claude --version.

2

Installer Ollama

Téléchargez Ollama depuis ollama.com/download (installateur Windows et Mac). Sur Linux :

curl -fsSL https://ollama.com/install.sh | sh

Une fois installé, Ollama tourne en arrière-plan sur l'adresse http://localhost:11434.

3

Télécharger un modèle de code open-source

Récupérez un modèle spécialisé en programmation. Qwen2.5-Coder est le meilleur choix pour débuter :

ollama pull qwen2.5-coder:7b

Le téléchargement fait environ 4,7 Go. Si vous avez 16 Go de RAM ou plus, essayez la version qwen2.5-coder:14b pour de meilleurs résultats.

4

Installer le routeur claude-code-router

Ce paquet traduit les requêtes entre Claude Code et Ollama :

npm install -g @musistudio/claude-code-router
5

Configurer le routeur vers Ollama

Créez le fichier ~/.claude-code-router/config.json (sur Windows : C:\Users\VotreNom\.claude-code-router\config.json) avec ce contenu :

{ "Providers": [ { "name": "ollama", "api_base_url": "http://localhost:11434/v1/chat/completions", "api_key": "ollama", "models": ["qwen2.5-coder:7b"] } ], "Router": { "default": "ollama,qwen2.5-coder:7b" } }

La clé api_key peut contenir n'importe quoi : Ollama ne vérifie aucune clé en local.

6

Lancer Claude Code en mode gratuit

Placez-vous dans le dossier de votre projet, puis démarrez Claude Code via le routeur :

cd mon-projet ccr code

Claude Code s'ouvre normalement, mais chaque réponse est générée gratuitement par votre modèle local. Tapez votre première instruction, par exemple « explique-moi la structure de ce projet ».

Astuce vérification
Pendant que Claude Code travaille, ouvrez un second terminal et tapez ollama ps. Si votre modèle apparaît comme actif, c'est la preuve que le calcul se fait bien en local - donc gratuitement.

Les limites à connaître (la vérité)

Soyons honnêtes : cette méthode est gratuite, mais elle n'égale pas le vrai Claude Code. Voici exactement ce que vous gagnez et ce que vous perdez.

Ce que vous perdez

  • La puissance. Un modèle 7B ou 14B en local est loin derrière Claude Sonnet ou Opus. Sur des tâches complexes, il fait plus d'erreurs.
  • La vitesse (sans GPU). Sur un ordinateur sans carte graphique dédiée, les réponses sont plus lentes.
  • Le contexte. Les modèles locaux gèrent moins de fichiers à la fois qu'un Claude complet.

Ce que vous gagnez

  • Zéro coût récurrent et aucune carte bancaire.
  • La confidentialité totale - votre code ne quitte jamais votre machine.
  • Le mode hors ligne - une fois installé, ça marche sans internet.
  • L'apprentissage - vous maîtrisez le workflow agentique sans dépenser un franc.
Mon verdict honnête
Utilisez cette méthode pour apprendre, expérimenter et coder hors ligne sans dépenser. Pour un travail client sérieux ou des projets complexes, le vrai Claude (via Pro ou API) reste supérieur. Beaucoup de développeurs gardent les deux : Ollama pour les tâches simples et l'apprentissage, Claude payant pour le travail critique.

Questions fréquentes

Est-ce légal d'utiliser Claude Code avec Ollama ?

Oui. Claude Code autorise officiellement les points d'accès personnalisés via la variable ANTHROPIC_BASE_URL. Vous utilisez des modèles open-source sous licence ouverte, pas les modèles Claude d'Anthropic. Il n'y a aucun piratage ni contournement de paiement - vous remplacez simplement le moteur par une alternative gratuite que vous avez le droit d'utiliser.

Claude Code avec Ollama est-il vraiment 100 % gratuit ?

Oui, hors coût d'électricité. Ollama et les modèles open-source sont gratuits. Vous n'avez besoin d'aucun abonnement, d'aucune clé API payante et d'aucune carte bancaire internationale. C'est le principal avantage pour les entrepreneurs et étudiants africains.

Quelle configuration faut-il pour faire tourner un modèle en local ?

Comptez environ 8 Go de RAM pour un modèle 7B, 16 Go pour un 14B et 32 Go (ou un GPU) pour un 32B. Sans carte graphique dédiée, la génération est plus lente mais reste utilisable pour apprendre et coder des tâches simples.

La qualité est-elle la même que le vrai Claude ?

Non, et il faut être clair là-dessus. Les modèles open-source en local sont nettement moins puissants que Claude Sonnet ou Opus. Cette méthode est idéale pour apprendre, coder hors ligne et préserver sa vie privée. Pour des tâches complexes ou du travail client, le vrai Claude reste supérieur.

Ça marche sur Windows, Mac et Linux ?

Oui. Ollama, Node.js et claude-code-router fonctionnent sur les trois systèmes. La procédure est identique, à part la commande d'installation d'Ollama (installateur graphique sur Windows et Mac, script sur Linux).

Peut-on utiliser le vrai Claude Code gratuitement ?

Le seul accès gratuit officiel à Claude est claude.ai (le chat web), qui n'inclut pas Claude Code. Claude Code nécessite un abonnement Claude Pro/Max ou des crédits API. La méthode Ollama décrite ici est donc la seule façon d'obtenir l'expérience Claude Code sans payer.

Conclusion

Vous savez maintenant comment avoir Claude Code gratuitement. Le montage tient en trois pièces : Claude Code pour l'interface, Ollama pour faire tourner un modèle gratuit en local, et claude-code-router pour les relier. Aucun abonnement, aucune carte bancaire.
